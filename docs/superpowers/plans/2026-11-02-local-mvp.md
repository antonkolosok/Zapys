# Zapys Local MVP Implementation Plan

> For agentic workers: REQUIRED SUB-SKILL superpowers:subagent-driven-development. Execute tasks in numeric order, one implementation task at a time. Each ends with tests, independent review and a root-owned commit. User authorized autonomous execution and explicitly requested sequential tasks using installed Superpowers 7.0.1.

**Goal:** Native local SQLite Android/iPhone apps, tested and proposed in an unmerged PR to antonkolosok/Zapys.

**Architecture:** Kotlin native Android and SwiftUI iPhone with pure domain rules and repository interfaces. SQLite transactions persist UUID entities and ordered appointment snapshots. Local profile and manual messenger handoff are labelled honestly; future cloud adapters implement authentication/delivery.

**Tech Stack:** Kotlin 2.1.20, AGP 8.9.2, Gradle 8.11.1, JDK17, Android SDK35/min26, SQLiteOpenHelper, JUnit; Swift package/SwiftUI/SQLite3/XCTest, iOS17; GitHub Actions Linux/macOS.

**Spec:** `docs/REQUIREMENTS.md`; visual guide `docs/DESIGN.md`.

## Global Constraints

- Ukrainian UI, FIVE services per appointment, ONE Free reminder per appointment.
- Client name/phone required; service duration/price/note optional; unknown price differs from zero.
- Stable UUIDs, versioned SQLite, atomic writes, durable reopen, ordered historical snapshots.
- End > start, end <= 23:59, explicit conflict confirmation; adjacent/cancelled/self excluded.
- No cloud/authentication/delivery success claims without a real service. No automatic external messages in tests.
- Do not merge, publish a release, expose credentials or commit SDK/build outputs.
- Preserve both approved HTML files. Root integrates commits; workers modify only assigned task files.

## Review Focus

1. End-of-day/adjacency: task2/3 domain and task8/9 resize tests.
2. Historical snapshot/order/null money: task2/3 persistence and task6/7 editor tests.
3. Failed transaction leaves no orphaned appointment/reminder: task2/3 persistence tests.
4. Reschedule/cancel removes stale reminders; sharing is not sending: task10/11 tests.
5. Denied contacts/notification permission and restart: task10/11 device tests.
